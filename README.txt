AISHWARYA KARLE — PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract aishwarya_portfolio.zip.
2. Open the extracted folder.
3. Double-click index.html to view the website in Chrome.

HOW TO PERSONALIZE BEFORE SHARING WITH COMPANIES
1. Open index.html in Notepad or VS Code.
2. Replace YOUR_EMAIL@example.com with your real professional email (in both the mailto link and visible text).
3. Replace the LinkedIn and GitHub links with your actual profile URLs.
4. Check every project description and change it to match what you actually built.
5. If you have a resume PDF, add it to this folder and add a Resume link/button in index.html.
6. Optional: Replace the “AK” initials card with a professional photo you choose.

FILES
- index.html: portfolio content
- style.css: responsive styling
- script.js: mobile navigation and current year

NOTES
- This is a static website; it does not need a backend or paid hosting.
- You can publish it for free with GitHub Pages after creating a GitHub account/repository.
- Keep the contact details accurate and only list skills you can explain in an interview.
